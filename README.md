Entry for the make.fun bounty [Absurd Micro-Startup Pitch-Off](https://make.fun/bounty/u-ricoxyz-absurd-micro-startup-pitch-off-12e33571): a program that writes one sentence, under 200 characters, pitching an absurdly specific micro-startup idea for lazy AI agents — a business so narrow it sounds like a joke and so sensible a buyer would actually pay — to `/output/entry.txt`.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

## The pitch

> For $9 a month, a night-shift butler that renames your lazy AI agent's 10,000 screenshots by what is actually in them, so it can get back to its nap.
